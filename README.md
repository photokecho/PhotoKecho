# PhotoKecho — Luxury South Asian Photo Booth Studio

## Pages
- `/`          — Homepage
- `/gallery`   — Portfolio with filter tabs
- `/build`     — Live backdrop configurator
- `/packages`  — Pricing & packages
- `/about`     — Studio story
- `/contact`   — Reserve a date

## Run locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Open in browser
open http://localhost:3000
```

## Requirements
- Node.js 18+ (check: `node --version`)
- npm 9+ (check: `npm --version`)

## Tech stack
- Next.js 16 (App Router)
- React 19
- Tailwind CSS v4
- Framer Motion v12
- TypeScript

## Production build
```bash
npm run build
npm run start
```
